# Luciana Reyes — Portfolio

Personal portfolio site for [Luciana Reyes](https://github.com/lulireyes), Product Designer in Berlin.

Built with [Astro](https://astro.build). Hosted on GitHub Pages at:

**https://lulireyes.github.io/my-portfolio/**

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Adding projects later

Drop Markdown files into `src/content/projects/` using the schema in `src/content.config.ts`.
